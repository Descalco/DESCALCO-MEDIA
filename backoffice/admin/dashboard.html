🎯 Backoffice Guide

📋 Project Management

  • Add Project: Click "+ Add Project" to create new projects
  • Edit Project: Click "Edit" on any non-hardcoded project
  • Delete Project: Click "Delete" to remove projects permanently
  • Drag & Drop: Drag projects to reorder them in your portfolio

👁️ Visibility Control

  • Show/Hide: Toggle project visibility with the eye icon
  • Featured: Mark important projects as featured
  • Order: Drag projects to change display order

🔧 Project Types

  • Simple: External links (YouTube, etc.)
  • Case Study: Full detailed pages you create
  • Hardcoded: Original projects (read-only)

🚀 Publishing Workflow

  • 1. Add/edit projects in backoffice
  • 2. Close backoffice when done
  • 3. Run update-portfolio.bat
  • 4. Your portfolio updates automatically!

📊 Analytics & Media

  • Analytics: View project performance stats
  • Media Manager: Upload and manage files
  • File Types: Images, videos, PDFs supported

💡 Pro Tips

  • Use descriptive titles and tags for better SEO
  • Upload high-quality cover media
  • Keep descriptions concise but informative
  • Regular backups are automatically created

📋 How to Update Your Portfolio

After adding or editing projects:

  1. Close the backoffice when you're done
  2. Run the update-portfolio.bat file in your main folder
  3. Your portfolio will automatically include all new projects
  4. No need to keep the backoffice running!

💡 Tip: Your portfolio works independently of this backoffice. The update script copies your projects to a static file that loads instantly.
